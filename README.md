## 🇧🇷 Português

Sistema de quilometragem e desgaste de peças para FiveM, totalmente **standalone** graças ao [fivem_bridge](https://github.com/Pierremoraes-ofc/Fivem_bridge).
Rastreia os KM rodados por veículo, persiste no banco de dados e aplica sintomas físicos e visuais progressivos conforme as peças se desgastam.
Compatível com **ESX**, **QBCore**, **QBox**, **ox_core** e **NDCore** — a detecção de framework é automática via bridge.
As peças têm durabilidade sorteada por faixa configurável, e os efeitos (fumaça, vibração, pneu furado, motor engasgando) são ativados por threshold e podem ser habilitados individualmente.

**Dependências:** `oxmysql` · `ox_lib` · `fivem_bridge`

---

## 🇺🇸 English

A mileage tracking and parts wear system for FiveM, fully **standalone** powered by [fivem_bridge](https://github.com/Pierremoraes-ofc/Fivem_bridge).
Tracks kilometers driven per vehicle, persists data to the database and applies progressive visual and physical symptoms as parts degrade.
Compatible with **ESX**, **QBCore**, **QBox**, **ox_core** and **NDCore** — framework detection is automatic via the bridge.
Parts have randomized durability within configurable ranges, and effects (smoke, camera shake, tyre burst, engine stall) are activated by threshold and can be toggled individually.

**Dependencies:** `oxmysql` · `ox_lib` · `fivem_bridge`
